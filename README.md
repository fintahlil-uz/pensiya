# FinTahlil.uz pensiya hisoblagichi

O‘zbekistonda pensiya miqdorini taxminiy hisoblaydigan bir sahifali vosita: yoshga doir, imtiyozli, nogironlik va boquvchisini yo‘qotganlik pensiyalari hamda ijtimoiy nafaqalar.

Sayt: https://fintahlil-uz.github.io/pensiya/

Hisob “Fuqarolarning davlat pensiya ta’minoti to‘g‘risida”gi Qonun va PF-115 farmoni (2026) asosida. Natija taxminiy, rasmiy hujjat emas.
